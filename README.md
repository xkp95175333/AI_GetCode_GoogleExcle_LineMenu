# Google Sheets → LINE Group

ตัวอย่าง Apps Script สำหรับส่งตารางนัดหมายทั่วไปจากแถวที่เลือกใน Google Sheets ไปยัง LINE Group

- `Code.gs`: เมนูในชีต, ดูตัวอย่าง, และส่งข้อความ
- `SETUP.md`: วิธีตั้งค่าและใช้งาน

คอลัมน์ที่ใช้: A=วันที่, B=เวลา, C=รายการนัดหมาย, D=สถานที่

เริ่มต้นโดยทำตามคู่มือ `SETUP.md` อย่าเผยแพร่ LINE token และแชร์เฉพาะข้อมูลที่ได้รับอนุญาต
